Como funciona a cruzadinha

Foque uma célula para selecionar a palavra. Em cruzamentos, clique novamente para alternar a direção. Pressione Enter para conferir.

Objetivo

Preencha a grade com as palavras descritas nas pistas.

Escolher uma palavra

Clique ou foque uma célula, clique no número da palavra (a definição aparece num balão), clique numa pista da lista lateral ou use as setas ‹ e › acima da grade para navegar na ordem dos números.

Cruzamentos

Onde duas palavras se cruzam, clique de novo na mesma célula para alternar entre horizontal e vertical. Se duas palavras começam na mesma célula, os dois números aparecem juntos (ex.: 1, 10) e cada clique alterna entre elas.

Digitar

Digite as letras; o cursor avança sozinho. Backspace volta, e as setas do teclado movem entre células. Maiúsculas, acentos, espaços e hífens não importam.

Conferir

Com a palavra completa, pressione Enter. Se estiver certa, ela fica verde com ✓ e bloqueada; se estiver errada, fica vermelha por um instante e você pode corrigir. Com a palavra incompleta, nada acontece.

Revelar

No botão Revelar você pode mostrar uma célula, uma palavra inteira ou a cruzadinha toda. Letras reveladas ficam em destaque âmbar.

Observação

A cruzadinha é um jogo livre e não altera seu progresso oficial.
